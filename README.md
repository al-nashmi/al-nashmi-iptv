# مشغل التلفزيون (Android TV)

برنامج لأجهزة Android TV وGoogle TV وFire TV يشغّل اشتراكات **Xtream Codes** وقوائم **M3U**.

## المزايا
- دخول بحساب Xtream (رابط السيرفر + اسم المستخدم + كلمة المرور) أو برابط M3U.
- البث المباشر، والأفلام، والمسلسلات (المواسم والحلقات).
- تصنيفات على جانب، والقنوات على الجانب الثاني، مع بحث.
- المفضلة: اضغط مطولاً على زر OK فوق أي قناة.
- داخل البث المباشر: زر فوق أو CH+ للقناة التالية، وزر تحت أو CH- للقناة السابقة، وزر OK يعرض اسم القناة.
- إعادة محاولة تلقائية إذا انقطع البث.
- اختيار صيغة البث المباشر: TS أو HLS (m3u8). إذا ما اشتغلت القنوات بصيغة، جرّب الثانية.

## الرقابة العائلية
من الشاشة الرئيسية اضغط على **الرقابة العائلية**. أول مرة يطلب منك تختار رمز PIN، وبعدها ما تنفتح الإعدادات إلا بالرمز.
- **حظر المحتوى الإباحي** (مفعّل افتراضياً): يخفي التصنيفات والقنوات والأفلام اللي في اسمها كلمات إباحية بأكثر من 20 لغة، ويخفي أي محتوى مزود الخدمة معلّمه بعلامة `is_adult`.
- **حظر الأغاني والرقص** (مفعّل افتراضياً): يخفي قنوات الأغاني والكليبات والرقص، مثل Rotana Clip وMazzika وMTV ووناسة. قنوات القرآن مستثناة.
- **كلمات إضافية**: أي كلمة تكتبها هنا تنحظر.
- **العمر المسموح** للأفلام والمسلسلات: للجميع، +7، +12، +15، أو بدون حد. المحتوى اللي تصنيفه أعلى من العمر المختار يتمنع، ويقدر الأب أو الأم يفتحه بالرمز.
- **إذا كان التصنيف غير معروف**: اسمح، أو نبّه، أو امنع.
- **مفتاح TMDB** (اختياري): يجيب التصنيف العمري من themoviedb.org للأفلام اللي ما لها تصنيف عند مزود الخدمة.

قائمة الكلمات موجودة في `app/src/main/assets/filter_words.json`، وتقدر تعدّلها.

> الفلتر يعتمد على أسماء القنوات والأفلام والتصنيفات. ما يقدر يحلل محتوى الفيديو نفسه، فممكن يفوته شيء اسمه عادي.

## البناء
1. افتح مجلد `TvPlayer` في Android Studio.
2. انتظر حتى ينتهي Gradle من التحميل.
3. من القائمة: Build ← Build APK(s).
4. الملف يطلع في `app/build/outputs/apk/debug/app-debug.apk`.

## التثبيت على التلفزيون
فعّل وضع المطوّر على التلفزيون، وشغّل خيار تصحيح أخطاء USB أو تصحيح الأخطاء عبر الشبكة، وبعدين نفّذ هالأمرين:
```
adb connect <TV-IP>:5555
adb install -r app-debug.apk
```
أو انسخ ملف APK على فلاشة وثبّته من تطبيق مدير ملفات مثل "Downloader" أو "File Commander".
